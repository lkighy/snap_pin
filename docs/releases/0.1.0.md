# snap_pin 0.1.0 发布说明

`0.1.0` 是平台抽象优先的技术预览版。当前目标是确认桌面壳、设置页、托盘、核心事件流、模型管理和平台能力边界可以稳定协作，而不是交付完整截图、OCR、翻译和安装分发体验。

## 可运行范围

- Windows 是 0.1 的首个可运行目标：主窗口、托盘、设置页、Tauri commands、模型列表和 MVP 事件流可用于 smoke test。
- macOS/Linux 当前只完成能力边界准备：平台能力以 `Unavailable`、`NeedsSetup` 或 `PermissionDenied` 等状态表达，不承诺真实截图、系统 OCR、全局热键或 overlay 行为。
- `--mvp-cli` 是发布验收用 mock 成功流，用于证明 capture、OCR、翻译、history 事件形状已经贯通。

## 默认构建限制

- 默认构建未启用本地 OCR native runtime。真实本地 OCR 路径应显示 `local_ocr_runtime_disabled`，不能自动回退 mock。
- 默认构建未启用本地翻译 native runtime。真实本地翻译路径应显示 `local_translate_runtime_disabled`，不能自动回退 mock。
- `--mvp-cli` 的 mock 成功流只用于发布验收和演示，不代表默认 GUI/provider 路径已经具备真实 OCR/翻译推理能力。
- `tauri.conf.json` 中 `bundle.active` 仍为 `false`，0.1 不做安装包、签名、自动更新或正式分发 bundle。

## 已验证

- GUI smoke 已验证：主窗口、托盘、设置页、OCR/翻译禁用态可打开并显示预期状态。
- MVP CLI 预期事件流：

```text
CaptureStarted
CaptureFinished
OcrQueued
OcrCompleted
TranslationQueued
TranslationCompleted
history: 1 ocr result(s), 1 translation(s)
```

- MVP CLI 不应输出 `local_ocr_runtime_disabled` 或 `local_translate_runtime_disabled`。

## 验证命令

```powershell
cargo fmt --check
cargo check --workspace --no-default-features
cargo check --workspace
pnpm --dir apps/tauri_desktop/ui build
pwsh scripts/check-platform-boundaries.ps1
cargo run -p tauri_desktop --target-dir target\mvp-check -- --mvp-cli
```

可选 native runtime 预检：

```powershell
pwsh scripts/check-ocr-rs-windows.ps1
pwsh scripts/check-translate-ct2-windows.ps1
```

## 非目标

0.1 不承诺完整透明 overlay 截图体验、真实 WGC/DXGI 捕获、多显示器/DPI 完整适配、开箱即用本地 OCR/翻译推理、外部 OCR/翻译 API、密钥安全存储、安装包、代码签名、自动更新或与 Snipaste 对齐的完整标注工具。
